# Речь дошла до склада

*Впервые команда из разговора прошла через GitHub, была исполнена на собственном компьютере, обратилась к реальному Wildberries и вернулась в разговор с проверяемым результатом.*

Утро начиналось с кнопок, неработающего редактора, испорченных выгрузок, внутренних ошибок и необходимости собственноручно исправлять десятки карточек. Это была прежняя модель: человек обслуживает интерфейс, интерфейс иногда отвечает, но не обязан становиться понятным.

Затем изменился не код ТН ВЭД. Изменилась **топология действия**.

Человек сказал: «Тестируй». Собеседник зарегистрировал задачу в GitHub. Постоянный исполнитель на Windows прочитал её, обратился к WB Content API и вернул результат. GitHub закрыл задачу, собеседник прочитал ответ.

**Слова впервые стали операцией без ручного перехода в чужую панель.**

Это **не свидетельство юридической неправильности кода**. Это первое достоверное различение между кодом в документе, полем товарной карточки и справочником платформы.

## Что произошло в действительности

Не построен «свой Wildberries». Не устранены все обязательства, ошибки и посредники. Но появилась воспроизводимая новая способность:

**намерение → зарегистрированное задание → исполнение → проверенный факт → возвращение в диалог.**

Раньше каждый следующий шаг требовал от собственника памяти, ручного труда и очередного интерфейса. Теперь появилась возможность переносить исполнение за пределы внимания, не теряя наблюдаемости.

GitHub здесь не склад смыслов и не магический компьютер. Он стал **регистратором перехода**.

ONTOS.OPERA ещё предстоит научиться изменять карточки, управлять ценами и собирать каналы. Но первый контур уже прошёл реальный эксперимент.

> **Мы не автоматизировали кнопку. Мы изменили место, из которого совершается действие.**

Редакция фиксирует: это произошло. Следующая задача: найти доступный код ТН ВЭД по реальному справочнику WB, не подменяя классификацию догадкой.
