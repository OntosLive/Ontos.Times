# АРХИВНЫЙ ВЫПУСК № 006

**28 сентября 2026**

## КИОСК № 42 СНОВА В ЭФИРЕ

На старой газетной вырезке из Грозного сохранилась фотография Марии Ивановны Аврамко.

Под ней напечатано:

> «Газетно-журнальный киоск № 42, где работает Мария Ивановна Аврамко, популярен у грозненцев. И не потому, что он расположен в центре города — на улице Ленина, а потому, что работающий тут киоскер добр и внимателен к покупателям».

Дальше газета отмечает и её производственные показатели.

Это был не просто продавец печати.

Это был человеческий узел между типографией и городом.

Газета приходила пачкой.
Потом проходила через её руки.
Потом становилась утром конкретного человека.

Кто-то покупал номер.
Кто-то разговаривал.
Кто-то приходил именно к ней.

А потом произошло странное замыкание петли:

**газета, которую она распространяла, сама написала о ней.**

новостью;

архивом;  
обёрткой;  
растопкой;

Сегодня она сообщает:

**СРОЧНО.**

Завтра становится вчерашним номером.

Через десятилетия вдруг превращается в свидетельство о человеке, которого уже нельзя встретить у киоска.

Материя говорит:

**я целлюлоза.**

Смысл отвечает:

**пока кто-то способен меня прочитать, я ещё в эфире.**

## ГРОЗНЫЙ → КРАСНОДАР → GITHUB

Потом в семейной памяти появляется другой кадр.

Краснодар.

Газеты и книги уже идут вместо туалетной бумаги в уличный туалет.

Никакой сакральности.

Бумага возвращается к своей материальности.

И вот спустя поколения возникает ещё один поворот.

Правнук Марии Ивановны запускает собственную газету.

Без киоска.
Без типографии.
Без пачки свежей бумаги.
Без доставки.

Есть разговор.
Есть файл.
Есть Git.
Есть публичная страница.

Функция возвращается в другой материи.

## ЧЕТЫРЕ ПОКОЛЕНИЯ ИНФРАСТРУКТУРЫ

Тогда:

**типография → пачка газет → киоск → Мария Ивановна → читатель**

**разговор → файл → GitHub → Pages → браузер**

Технология полностью другая.

> **сигнал передан в окружающий мир.**
