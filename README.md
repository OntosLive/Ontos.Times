# ONTOS.TIMES

**Газета различений. Персонаж-свидетель. Телеграф живых событий.**

Что-то произошло → стало различимым → появился выпуск. Без контент-плана, нормы публикаций, регистрации, новой компании или обязательства.

## Два масштаба публикации
- **Свёрнутая сцена:** `index.html`, газетная первая полоса; предлагает вход и обязательную ссылку на полный номер.
- **Развёрнутая сцена:** `issues/YYYY-MM-DD-slug.md`, собственный архивный адрес `/archive/NNN/`, восстановимая траектория мысли; раскрытие через онтостендап, фельетон, архитектуру, сцену и манифест.
- **Подшивка:** `archive/index.html` перечисляет все номера автоматически через Jekyll.

## Публикация нового номера
1. Выбрать следующий номер и создать Markdown с YAML front matter (`layout: issue`, `number`, `edition`, `date_label`, `title`, `description`, `permalink`).
2. Развернуть полный материал, сохранить первичное событие и точность различений.
3. Создать свёрнутую первую полосу в `index.html`, обязательно добавить ссылку на `/archive/NNN/`.
4. При необходимости добавить локальные иллюстрации в `assets/`; использовать `figure`, осмысленный `alt`, подпись и права для внешних фотографий.
5. Проверить главную, мобильное отображение, архив, ссылки, front matter и доступность текста без картинок.

Стили в `styles.css`. Канон в `docs/canon.md`. Конфигурация Jekyll в `_config.yml`.

**Минимум интерфейса, максимум различимости. Редакция охуела. Выпуск состоялся.**
