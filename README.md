# ONTOS.TIMES

**Газета различений. Персонаж-свидетель. Телеграф живых событий.**

ONTOS.TIMES не является медиа-компанией, контент-планом, блогом или обязательством регулярно что-либо производить.

> Что-то произошло → это стало различимым → появился выпуск.

Газета может молчать неделю. Может выпустить три экстренных номера за ночь. У неё нет долга перед алгоритмом, аудиторией или расписанием.

## Формула

**разговор → различение → выпуск → страница → архив**

Не каждую мысль нужно превращать в проект.
Не каждую возможность нужно реализовывать.
Иногда достаточно дать событию форму, чтобы оно осталось в мире.

## Кто такой ONTOS.TIMES

Не площадка, а персонаж.

ONTOS.TIMES приходит туда, где что-то произошло, и говорит:

> Это было. Я это видел. Вот номер выпуска.

## Два режима

### Обычный выпуск
Несколько связанных текстов, фигур, наблюдений и сцен.

### Экстренный выпуск
Один удар. Одна фраза. Одно событие. Один знак.

## Эстетика

Газета и текст.

Без интерфейсного цирка.
Без обязательной регистрации.
Без бесконечных карточек, панелей и виджетов.

**Минимум формы, максимум различимости.**

## Принцип Морзе

**сигнал → различение → текст → выпуск → пауза**

## Нулевой закон

> Форма должна появляться быстрее, чем обязательства успевают вокруг неё зарасти.

## Технический принцип

Сначала максимально простая статическая газета:

- HTML
- CSS
- Markdown-выпуски
- Git как история
- GitHub как архив траектории

Сервер, база данных, Next.js и автоматизация появляются только тогда, когда возникает реальная функция, которой без них тесно.

## Редакционная позиция

ONTOS.TIMES не обязан продавать.
Не обязан расти.
Не обязан становиться бизнесом.

Он может просто оставлять следы.

**Редакция охуела. Выпуск состоялся.**
